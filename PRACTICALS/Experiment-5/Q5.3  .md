# Experiment 5.3

## Problem Statement
Write a PL/pgSQL program that declares an integer variable VAL and checks its value using an IF–ELSIF–ELSE conditional statement.

The program should display the following messages based on the value of VAL:

If VAL is between 1 and 10 (inclusive), display:

YOUR VALUE IS <VAL> AND RANGE IS BETWEEN 1 TO 10

If VAL is between 11 and 20 (inclusive), display:

YOUR VALUE IS <VAL> AND RANGE IS BETWEEN 11 TO 20

Otherwise (if VAL is greater than 20 or less than or equal to 0), display:

YOUR VALUE IS <VAL> AND VALUE IS GREATER THAN 20

## Objective:
Use the IF–ELSIF–ELSE control structure in PL/pgSQL to categorize the value of an integer variable and print an appropriate message using RAISE NOTICE.
